# P-3b 真机验收清单（只有用户能做）

这份清单不需要会写代码。照着做，把没通过的项记在最后的「结果」里交回即可。

## 0. 准备

1. 手机浏览器打开 [**https://shawnyann2025-dot.github.io/EAR-TR/**](https://shawnyann2025-dot.github.io/EAR-TR/) （开发者交付时会说明当前部署的是哪个版本；设置页底部能看到版本号，请把它记在「结果」里）。请至少测一种：iPhone 的 Safari，或安卓的 Chrome（两种都测更好）。把手机型号和系统版本记在「结果」里。
2. **iPhone 请先把侧边的静音键拨到「关闭静音」（看不到橙色）**。静音键打开时网页声音会被整个静音，会误以为没声音。
3. 尽量用有线耳机。蓝牙耳机有延迟，会影响打拍题的判定；如果只能用蓝牙，请在「结果」里注明。
4. 第 1 节的音色调试页地址是 [https://shawnyann2025-dot.github.io/EAR-TR/#dev](https://shawnyann2025-dot.github.io/EAR-TR/#dev)。

> 开发者本地调试仍可用 `npm run dev` + 局域网地址，但局域网 http 下手机不给麦克风、不启用离线缓存，不能用于验收。

## 1. 音色实听（主 spec §16.3）

打开第 0 节第 4 条的调试页地址，戴耳机逐项确认（十项来自 P-1 计划 Task 13 Step 7；主 spec §16.3 只给出了数量，没有逐条列出）：

- [ ] 1. 点「下一题」能听到声音，无爆音、无削波
- [ ] 2. L0：能听清 ii–V–I 终止式，之后目标音清晰可辨
- [ ] 3. L1：终止式变短，仍能建立调感
- [ ] 4. L2：低音持续贯穿整题
- [ ] 5. L3：开头一声主音后消失，目标音在静默中出现
- [ ] 6. L4：低音在题目中途撤走
- [ ] 7. 切换若干题，四种音色听感确实不同（听不出区别则该变异轴无效）
- [ ] 8. 连点「下一题」十余次，调在变化
- [ ] 9. 切换三种显示皮肤，「看答案」显示相应记法
- [ ] 10. 音量调到日常音量，低音 drone 不会盖住目标音
- [ ] 「人声」与「弦乐」听得出区别（分不出就记下来，需改 `oscType`）
- [ ] 语境（终止式）末尾不拖尾进目标音（FWD-5）

## 2. 完整练一场

- [ ] 首次打开看到周期说明与耳机建议，做完分级测试，进入首页
- [ ] 练完一整场 25 分钟会话：选择、听写、唱（自评）、打拍四种控件都出现过且能用
- [ ] 答题按钮都在屏幕下 1/3，单手拇指够得到
- [ ] 答错时自动重放，「慢速再听」可用；音级题有音阶条
- [ ] 音型符号（二分音符、十六分音符、休止符等）在手机上能正常显示，不是方块或问号
- [ ] 打拍题：点击区够大，连点不触发页面缩放或选中文字
- [ ] 练习中屏幕不熄灭（部分浏览器不提供「保持亮屏」，做不到就记一下，不算失败）
- [ ] 今日总结的数字合理

## 3. 打拍准确度

遇到打拍题时：

- [ ] 认真跟着节拍、卡在拍点上打：应判对（多打几题，大多数应对）
- [ ] 故意每下都晚半拍打：应判错
- [ ] 如果认真打也总是被判错或总是偏早/偏晚，记下用的是有线还是蓝牙耳机、手机型号

## 4. 中断与续起

- [ ] 练到中途切到别的应用再回来：显示「继续」，点击后重出同一道题
- [ ] 答题时锁屏，再解锁回来：显示「继续」，能接着做，没有丢题
- [ ] 练习时来电话或收到带提示音的通知：回到应用后显示「继续」，能接着做
- [ ] 答完一题、看着反馈画面时切到别的应用，过一会儿回来：不会自动跳到下一题；点「下一题」后新题能正常出声、能正常作答
- [ ] 打拍题的打拍过程中切走再回来：这题不算对错，「继续」后重出
- [ ] 练到中途关掉浏览器标签再打开：首页显示「继续今天的练习」，从中断处接着练

## 5. 其他流程

- [ ] 「结束本场」：点一下只变成红色的「确定结束本场？」，不会马上结束；4 秒内再点才结束；不点则自动恢复。暂停画面里的「结束本场」也一样，并且位置在「继续」下方、离得较远
- [ ] 总结页点「重练刚才错的这组」：能进入只含错题的练习，练完回到总结
- [ ] 回到首页后点「再练一场」：能开始新的一场
- [ ] 设置里切换显示方式（唱名/数字等），回到练习时题目和答案的记法随之改变
- [ ] 隔天再打开应用：首页是新的一天，点「开始今天的练习」开始新的一场，而不是接着昨天的

## 6. 导出与导入

- [ ] 设置 → 导出备份，得到 JSON 文件
- [ ] 再练几题后导入刚才的备份：进度回到导出时；可下载「导入前的自动备份」

## 7. 唱题音高检测（P-4b）

> 建议戴耳机；在安静的房间里做。新用户第一次会在「测一下你的音域」页请求麦克风权限；之后每次开始一场练习前，都会用 3 秒校准环境噪声——这 3 秒请保持安静。

- [ ] 新用户：音域页点「开始测定」后弹出麦克风权限请求，允许后提示「请保持安静 3 秒」；之后每次点「开始今天的练习」，也都会先出现这 3 秒校准提示
- [ ] 首次使用：分级之后进入「测一下你的音域」；唱最低音、最高音后显示的音域大致符合你的感觉（例如男声约 A2–G4、女声约 F3–C5）
- [ ] 遇到唱题：语境播完后显示「正在听…」，唱对应音级（每个音唱稳约 1 秒），唱满后自动判定
- [ ] 唱准：判对；**低一个八度唱**（男声唱女声音区的题）也判对
- [ ] 故意唱偏一个半音：判错，反馈里那个音标 ✗
- [ ] 不唱、等它超时：提示「没听到你唱」并播放目标音
- [ ] 「唱完了」可以提前结束
- [ ] 设置里把「唱题判定」改为「自评」：唱题变回「唱对了 / 没唱对」按钮；改回「音高检测」恢复
- [ ] 在浏览器设置里撤销麦克风权限后重新开始练习：提示「没有麦克风权限，唱题改为自评」，练习照常进行
- [ ] 设置里「重新测定」音域可用；选「女高」等声部预设后，唱题的目标音高听起来变化合理
- [ ] 男声、女声各测一次（条件允许）
- [ ] 练完一场后，浏览器的录音指示（红点/麦克风图标）会消失
- [ ] iPhone：练习中来电或切到别的应用再回来，唱题仍能收音（若一直显示没听到你唱，请记录）
- [ ] iPhone：中断后点「继续」，下一道唱题显示「正在听…」，不会立刻又回到「练习暂停了」（若反复回到暂停页，请记录）
- [ ] iPhone：音高检测模式下练习时，听辨题和节奏题的播放音量与「自评」模式相比没有明显变小或从听筒播放（若有，请记录——需要改为每道唱题单独开麦）

- [ ] 首页出现「挑战实战关」；进入后说明清楚（部分、重听规则、90% 标准、今天剩几次）
- [ ] 「播放整曲」：贝斯、和弦、旋律、鼓都听得清；**旋律不被和弦盖住**（若被盖住，请记录——需要把和弦音量从 0.22 调到约 0.16）
- [ ] P1：拍号题在第一句之前出现；只靠听能判断拍号
- [ ] 逐句作答：「重听本句」起止落在小节线上、听起来自然；「重听整曲」次数递减到 0 后不可用（开头的第一次「播放整曲」免费，之后最多再听 3 次）
- [ ] 手机上逐句作答区好用（音级、和弦、节奏型按钮都点得到）
- [ ] 提交后看到各部分百分比（标注「达标 / 未达标」）与逐句对照；拍号、新调主音显示所选与正确答案
- [ ] 没过：可以「换一段再试」，片段确实换了；第 4 次被拒
- [ ] 通过：首页阶段变成下一阶段
- [ ] 挑战中切到别的应用再回来：不算一次尝试（首页剩余次数不变）
- [ ] 难度感受：完成本阶段的人做这关，不靠猜、也不是做不出来（记录真实通过与否，用于之后的节奏裁定）

## 9. 安装与离线（P-6）

> 注意：iPhone 上从主屏幕打开的应用和 Safari 里的网页数据是分开的——安装后主屏幕应用里是空的，需要重新走一遍开屏引导；本节「数据还在」两项都在主屏幕应用里检查。（安卓 Chrome 安装的应用与浏览器共享数据。）

iPhone 与安卓各做一遍：

- [ ] 添加到主屏幕（iPhone：Safari 分享 →「添加到主屏幕」；安卓：Chrome 菜单 →「安装应用」或「添加到主屏幕」），图标与名称「练耳」正确
- [ ] 从主屏幕打开：全屏，没有浏览器地址栏
- [ ] 开飞行模式，从主屏幕打开：能进首页、能开始练习、有声音
- [ ] 设置页底部显示「版本 …· 数据格式 v2」，以及存储是否已持久化
- [ ] （开发者通知你有新版本后再做）回到首页出现「有新版本，点此更新」；练习页面里不会弹出；点了之后更新，之前的数据还在
- [ ] 关掉应用，隔一两天再打开，数据还在
- [ ] 从主屏幕打开时，唱的部分仍能收音（第 7 节任选两项重做）
- [ ] 点「播放」到听见声音，没有明显延迟（大约半秒以内）
