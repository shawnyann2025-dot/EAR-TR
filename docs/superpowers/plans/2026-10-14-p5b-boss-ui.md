# P-5b 实战关界面与接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让学习者在手机上真正挑战实战关：掌握度达标后首页解锁、分句作答、判定、记录尝试、通过即升阶段；删除 P-3 的实战关替身。

**Architecture:** 状态机的结束流程只报告「掌握度是否达标」，不再升阶段。存储新增 `bossAttempts`（IndexedDB 升到 v2）。运行时新增四个串行操作：`bossStatus`、`newBossChallenge`、`recordBossAttempt`。界面新增关卡页 `Boss.tsx`，复用 `SequenceControl`、`ChoiceControl` 与文案表，播放用 P-5a 的 `renderPiece` / `phrasePlan`。

**Tech Stack:** React 19、TypeScript、vitest + jsdom、fake-indexeddb。无新依赖。

**Spec:** `docs/superpowers/specs/2026-10-13-p5-boss-design.md`（P-5 spec）§4、§5 的 P-5b 测试与真机验收、§6 第二行；主 spec `docs/superpowers/specs/2026-08-24-ear-training-design.md` §8.2–§8.4、§10。

## Global Constraints

- 解锁条件：`evaluateGate(c, mastery, phaseId, true).blockingKeys.length === 0`（掌握度达标）。
- 通过标准：`gradeBoss(...).passed`（P-5a：各部分 ≥ 90%，≤ 10 个位置的部分允许错 1 个）。
- 每天最多 `BOSS_ATTEMPTS_PER_DAY = 3` 次（按 `dayIndex` 的本地日计）；中途离开不计次（只有提交才写尝试记录）。
- 整曲：开场「听整曲」一次，之后最多再听 `FULL_REPLAYS = 3` 次；每句无限重听。
- P1 的拍号题紧接在「听整曲」之后、任何乐句页之前，答后锁定。P5 的新调主音题在最后一页，作答区写明「第 5–8 小节按新调标注」。
- 已提交的乐句不能返回修改。
- 通过：`Profile.phaseId` → `nextPhase`（P5 无下一阶段时不变），写 `GateRecord { phaseId, passedOnDay }`；与 P-3a 的 `advancePhase` 一致——只在仍处于该阶段时推进。
- 存储：新实体 `BossAttempt { phaseId; day; seed; parts: Record<string, number>; passed: boolean; at: string }`；IndexedDB 新仓库 `bossAttempts`（autoIncrement）；`SCHEMA_VERSION = 2`；迁移只新增仓库；导出包新增 `bossAttempts`，v1 导出包导入时迁移为 `[]`。
- 删除：`BOSS_STANDIN_ACCURACY`、`bossPassed`、状态机结束流程里的 `advancePhase` 副作用与运行时对应分支。
- 作答前不显示知识点名称（P-2b §14）；文案用 `labelFor`，提示 id：旋律 `notate-melody`、和弦 `notate-chords`、节奏 `notate-patterns`、拍号 `which-meter`、新调主音 `new-tonic-degree`；调式一律 `'major'`。
- 依赖方向与零 IO 约束不变：`src/session/`、`src/storage/`（`indexeddb.ts` 除外）、`src/boss/` 零 IO。
- 测试命令：`npx vitest run <path>`；全量 `npx vitest run`；类型 `npx tsc --noEmit`；构建 `npx vite build`。组件测试首行写 `// @vitest-environment jsdom`。
- 每个任务结束提交一次，提交信息以 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` 结尾；不要提交 `.superpowers/` 下的任何文件，不要 `git add -f`。

```tsx
        <p>先听一遍整曲，再一句一句写出来。每句可以无限重听；整曲开场听一次后最多再听 {FULL_REPLAYS} 次。</p>
        <p>每个部分 ≥ 90% 才算通过（和弦、节奏可以错 1 个）。</p>
        {remaining !== null && <p>今天还能挑战 {remaining} 次。</p>}
        {error && <p className="error">{error}</p>}
        <button type="button" className="primary big" disabled={remaining === 0} onClick={() => void begin()}>开始</button>
        <button type="button" onClick={props.onExit}>返回</button>
      </main>
    )
  }

  if (!ch || !rendered) return <main className="page boss" />

  if (step.kind === 'result') {
    return (
      <main className="page boss">
        <h1>{step.grade.passed ? '通过！' : '这次没过'}</h1>
        {step.grade.passed && <p className="good">{step.advancedTo ? `升入 ${step.advancedTo}！` : '全部阶段完成！'}</p>}
        <BossResult challenge={ch} response={resp} grade={step.grade} scheme={scheme} />
        {!step.grade.passed &&
          (step.remaining > 0 ? (
            <button type="button" className="primary" onClick={() => void begin()}>换一段再试（今天还剩 {step.remaining} 次）</button>
          ) : (
            <p>今天的次数用完了，明天再来。</p>
          ))}
        <button type="button" onClick={props.onExit}>回首页</button>
      </main>
    )
  }

  const fullReplay = (
    <button type="button" disabled={replays <= 0} onClick={() => { setReplays((k) => k - 1); play(rendered.plan) }}>
      重听整曲（剩 {replays} 次）
    </button>
  )

  if (step.kind === 'listen') {
    return (
      <main className="page boss">
        <p>先完整听一遍。</p>
        <button type="button" className="primary big" onClick={() => play(rendered.plan)}>播放整曲</button>
        <button type="button" onClick={() => setStep(ch.parts.includes('meter') ? { kind: 'meter' } : { kind: 'phrase', i: 0 })}>开始作答</button>
      </main>
    )
  }

  if (step.kind === 'meter') {
    return (
      <main className="page boss">
        <p className="prompt-text">这首曲子是几拍子？（答后不能修改）</p>
        {fullReplay}
        <section className="answer-zone">
          <ChoiceControl
            ids={ch.alphabets.meter!}
            label={lab('which-meter')}
            enabled
            onAnswer={(id) => { setResp((r) => ({ ...r, meter: id })); setStep({ kind: 'phrase', i: 0 }) }}
          />
        </section>
      </main>
    )
  }

  if (step.kind === 'newTonic') {
    return (
      <main className="page boss">
        <p className="prompt-text">新调的主音是原调的哪个音级？</p>
        <section className="answer-zone">
          <ChoiceControl
            ids={ch.alphabets.newTonic!}
            label={lab('new-tonic-degree')}
            enabled
            onAnswer={(id) => { const final = { ...resp, newTonic: id }; setResp(final); void submit(final) }}
          />
        </section>
      </main>
    )
  }

  // 乐句页
  const i = step.i
  const ph = ch.phrases[i]
  const bars = ph.endBar - ph.startBar
  const last = i === ch.phrases.length - 1
  const groups: ('melody' | 'chords' | 'rhythm')[] = ['melody', ...(ch.answer.chords ? (['chords'] as const) : []), ...(ch.answer.rhythm ? (['rhythm'] as const) : [])]
  const done = (g: string) => phraseDone[`${i}:${g}`]
  const allDone = groups.every(done)
  const setPart = (g: 'melody' | 'chords' | 'rhythm', ids: string[]) => {
    setResp((r) => {
      if (g === 'melody') {
        const melody = r.melody.slice()
        melody[i] = ids
        return { ...r, melody }
      }
      const arr = (r[g] ?? Array(ch.piece.bars).fill('')).slice()
      ids.forEach((id, k) => { arr[ph.startBar + k] = id })
      return { ...r, [g]: arr }
    })
    setPhraseDone((d) => ({ ...d, [`${i}:${g}`]: true }))
  }
  const newKey = ch.piece.modulationBar !== null && ph.startBar >= ch.piece.modulationBar

  return (
    <main className="page boss">
      <header className="topbar"><span>第 {i + 1} / {ch.phrases.length} 句</span></header>
      <div className="row">
        <button type="button" onClick={() => play(phrasePlan(rendered, i))}>重听本句</button>
        {fullReplay}
      </div>
      {newKey && <p className="small">第 5–8 小节按新调标注</p>}
      <section className="answer-zone">
        {groups.map((g) =>
          done(g) ? (
            <p key={g} className="small">已提交</p>
          ) : (
            <SequenceControl
              key={`${i}:${g}`}
              length={g === 'melody' ? ph.melodyCount : bars}
              alphabet={g === 'melody' ? ch.alphabets.melody : g === 'chords' ? ch.alphabets.chords! : ch.alphabets.rhythm!}
              label={lab(g === 'melody' ? 'notate-melody' : g === 'chords' ? 'notate-chords' : 'notate-patterns')}
              enabled
              onSubmit={(ids) => setPart(g, ids)}
            />
          ),
        )}
        <button
          type="button"
          className="primary"
          disabled={!allDone}
          onClick={() => (last ? afterPhrases() : setStep({ kind: 'phrase', i: i + 1 }))}
        >
          {last && !ch.parts.includes('newTonic') ? '提交关卡' : '下一句'}
        </button>
      </section>
    </main>
  )
}
```

（`fillSequence` 测试按 `.sequence` 元素的出现顺序定位各组：已提交的组被替换成「已提交」段落，不再是 `.sequence`——所以测试在提交第一组之后第二组的索引会变成 0。实现与测试二选一保持一致：**实现保留已提交组的 `.sequence` 外壳但禁用按钮**，或**测试每次都用索引 0**。选后者：把测试里第二组的索引改为 0，并在报告里说明。`submit` 里用到的 `resp` 在最后一句提交时必须包含刚提交的部分——`afterPhrases` 读到的是渲染时的 `resp`，而 `setPart` 是在点「提交」时更新的，到点「提交关卡」时已经渲染过，所以是最新的。）
